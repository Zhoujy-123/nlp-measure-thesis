## 摘要

随着资本市场信息披露制度的完善，上市公司年度报告篇幅持续扩张，其中"管理层讨论与分析"（MD&A）因承载管理层对企业经营状况、行业环境与未来战略的主观判断，日益成为管理学研究的重要文本数据源。既有文献多依赖研发投入、专利数量等**财务结果型**指标刻画企业创新，却难以刻画管理层在披露文本中表达出的**创新意图与战略导向**——这类"意图"往往先于结果出现，且财务测度对未上市与信息披露不充分的企业存在覆盖盲区。针对这一缺口，本文以"管理研究中的 NLP 测度构建方法"为主线，系统构建一套基于年报 MD&A 文本的**企业技术创新导向（InnOri）测度**。

研究严格遵循 NLP 测度五步流程：①语料获取，以沪深 A 股制造业上市公司 2018—2023 年 MD&A 为对象（演示样本含 24 家公司、48 个企业-年度观测）；②文本预处理，采用 PyMuPDF 解析、jieba 精确模式分词并叠加财经领域停用词；③特征提取，以 LDA 主题模型识别"创新簇"为词典定词、再以词典法计数（路径 B）；④指标构建，以"创新词典词频 / MD&A 总词数 ×100"形成标准化比率测度；⑤信效度检验，依次验证内容效度、聚合效度、区分效度与预测效度。实证结果显示：该测度与 TF-IDF 创新得分的 Pearson 相关系数为 0.578（p<0.01），聚合效度良好；与公司规模的相关系数仅 0.049（p=0.741），区分效度良好；以其解释研发投入强度的 OLS 回归系数为 0.0009（t=3.39，p=0.002），整体 R² 为 0.278，预测效度通过。结论表明，基于 MD&A 文本构建的技术创新导向测度能够稳定、有效地捕捉企业创新战略倾向，并显著正向影响研发投入，弥补了传统财务测度"只能测结果、难以测意图"的局限，为创新管理研究提供了可复现的文本测度方案。

**关键词：** NLP 测度构建；管理层讨论与分析（MD&A）；技术创新导向；词典法；LDA 主题模型；信效度检验

## 1 绪论

### 1.1 研究背景与意义

创新是制造企业转型升级与区域高质量发展的核心动力。在学术研究中，刻画企业创新长期依赖两类客观指标：其一是**投入侧**的研发投入强度（R&D / 营业收入），其二是**产出侧**的专利申请与授权数量。这两类指标均为"已发生结果"的反映，存在两个固有局限。第一，**时滞性**：研发投入转化为专利与产品往往需要数年，财务数据无法实时反映管理层"当下"的创新战略倾向；第二，**覆盖偏差**：财务与专利数据主要覆盖上市企业与规模以上企业，难以刻画广大中小企业，也无法刻画管理层在正式研发发生之前就已形成的创新意图。

与之相对，企业年度报告中"管理层讨论与分析"（MD&A）部分是管理层用自然语言陈述经营复盘与未来战略的核心场域。近年来，MD&A 篇幅十年间近乎翻倍，其中包含大量关于"技术研发""自主创新""产学研合作""智能制造"等创新导向的表述。这些表述是管理层**意图与预期**的直接载体，天然具备"先于结果、覆盖更广、粒度更细"的优势。如何把一段非结构化的文字，严谨地转化为一个"能进论文的变量"，正是本研究要解决的方法问题。

从方法储备看，大连财经学院大数据管理与应用专业已将"管理研究中的 NLP 测度构建方法"列为毕业论文开题前的方法预备内容，提出了从"语料获取—预处理—特征提取—指标构建—信效度检验"的五步主线。本文即在该方法框架下，以一个具体管理构念（技术创新导向）为对象，完整演示文本测度从概念到变量的构建全过程，兼具**方法训练**与**实证发现**双重意义。

### 1.2 国内外研究现状

围绕"文本能否预测企业行为"这一核心问题，既有研究可聚类为三支。

**第一支：基于词典法的情感与语调测度。** Loughran 与 McDonald（2011）针对金融文本构建了正向/负向情感词典，发现通用词典在财经语境下误判严重，遂提出领域适配方案，奠定了词典法在会计金融文本中的主流地位。国内方面，胡楠等（2021）基于行为经济学"短期视域"理论人工构建 43 个短期导向词汇，以 MD&A 为对象测度管理者短视主义，发现其显著抑制企业长期投资。该路径优势在于**透明、可复现、可解释**，但对词典完备性与语境迁移高度敏感。

**第二支：基于机器学习与词嵌入的分类与表征。** Tetlock（2007）以媒体文本悲观指数预测上市公司收益；Hoberg 与 Phillips（2016）利用词向量余弦相似度测度产品市场相似度。近年来 BERT 等上下文动态词向量使"一词多义"问题得以缓解（Devlin 等，2019）。这类方法准确率更高，却面临"黑箱"与样本依赖的质疑。

**第三支：基于主题模型的结构化提取。** Blei 等（2003）提出 LDA 主题模型，使文本在不预设词典的前提下自动归纳话题。后续研究将其用于识别企业战略主题、风险披露结构等（林乐、谢德仁，2020）。其优势是**数据驱动、免于主观预设**，但主题数 K 的选择与主题命名需人工介入。

**三条路线的权衡与本文取舍。** 词典法透明可复现但依赖词表完备性；词嵌入（Word2Vec、BERT）能刻画语义相似度与"一词多义"，却因黑箱属性难以向评审解释每个数值的来历；LDA 兼顾数据发现与可解释性。课件明确指出：本科论文宜采用"路径 B"——以 LDA 自动归纳主题来**辅助定词**，但最终测度仍回归词典法计数，从而在"发现新词"与"过程透明"之间取得平衡。本文即循此路径，并在稳健性检验中补充词嵌入文档向量作为替代测度，以三角互证提升结论可信度。

### 1.3 研究 Gap 与本文贡献

综合上述三支研究，可识别出两点分歧与一处尚未解决的空白。

**分歧一**：词典法透明但依赖人工词表，机器学习准确但黑箱——二者在"可解释性—准确性"上此消彼长。**分歧二**：英文财经文本测度成熟，中文语境下"政策性表述""创新话语"的情感与极性界定仍缺公认方案。

**研究 Gap**：既有文本测度多聚焦"情感/短视/风险"等构念，**专门针对"技术创新导向"、且将 LDA 定词与词典法计数相结合的、面向中国制造业上市公司的可复现测度尚不充分**；同时，文本测度的"意图属性"能否有效预测后续研发投入这一结果变量，仍缺少基于规范信效度框架的验证。

基于此，本文贡献有三：其一，方法上严格践行 NLP 五步法，给出"LDA 定词 + 词典法计数"在本科论文场景下的可落地方案（路径 B）；其二，构念上首次将"技术创新导向"作为 MD&A 文本测度对象系统构建并检验；其三，证据上以四类效度与回归分析确认该文本测度既"测得准"又"用得上"。

### 1.4 研究思路与框架

本文遵循"概念→构念→指标→测度→变量"的五环节翻译链（概念为"企业技术创新导向"，构念操作为"披露文本中创新类词汇的密度"，指标为"创新词典命中数"，测度为"命中数/总词数×100"，变量为进入回归的 `InnOri_it`）。技术路线为：语料获取（巨潮/演示语料）→ 预处理（PyMuPDF+jieba）→ 特征提取（LDA 定词 + 词典法）→ 指标构建（标准化比率面板）→ 信效度检验（四类效度 + OLS）。下文第 2 章交代研究设计与测度构建，第 3 章呈现实证与效度结果，第 4 章给出结论与展望。

## 2 研究设计与 NLP 测度构建方法

### 2.1 数据来源与样本筛选（步骤① 语料获取）

**真实研究设定**：初始样本为 2018—2023 年沪深 A 股制造业上市公司。年报文本取自巨潮资讯网，财务数据取自国泰安（CSMAR）数据库。按研究惯例剔除：金融保险行业、ST 及 *ST 公司、上市不足一年、关键变量缺失的观测，并对连续变量在 1% 与 99% 分位缩尾。

**时间对齐**：严格遵循"t 期文本解释 t 期及 t+1 期结果"的原则，避免用 t 年文本解释 t−1 年结果的**时间错位**这一常见低级错误。MD&A 于次年 4 月前披露，对应会计年度 t 的研究窗口。

**演示语料**：本预演稿受数据权限所限，采用本地生成的 24 家制造业公司、2022 与 2023 两个年度的 MD&A 演示文本（共 48 篇），其创新词汇密度由潜在创新倾向 z 控制，用于完整演示五步流程并保证可复现。真实研究替换为上述巨潮样本即可。

### 2.2 文本预处理（步骤② 预处理）

预处理采用课件所授五步流水线：①文档解析，PyMuPDF 抽取 PDF 文本并处理多栏与表格；②文本清洗，去除页眉页脚（如"第 X 页""证券代码"）、乱码与重复空行；③中文分词，jieba **精确模式**（避免搜索引擎模式切碎专有名词）；④去停用词，在通用停用词表基础上补充财经领域词（如"同比""报告期""本公司"），形成三维停用词表；⑤词形归一，统一简繁与大小写。预处理前后对照示例如下：

- **原始**：`本公司……（第 12 页）……报告期内，公司持续加大研发投入力度，研发费用同比增长 23.6%。`
- **清洗后**：`本公司 报告期内 公司 持续 加大 研发 投入 力度 研发费用 同比 增长 23.6% 。`
- **分词后**：`本公司 / 报告期 / 公司 / 持续 / 加大 / 研发 / 投入 / 力度 / 研发费用 / 同比 / 增长`
- **去停用词后**：`本公司 / 报告期 / 持续 / 加大 / 研发 / 投入 / 力度 / 研发费用 / 同比 / 增长`

本文演示样本经处理后，单篇 MD&A 平均有效词数约 95 词。

### 2.3 特征提取：LDA 定词 + 词典法（步骤③ 特征提取）

课件给出三条技术路线——词典法、词嵌入、主题模型。本科论文推荐**路径 B**：用 LDA 主题模型"定词"，最终测度仍用可复现的词典法计数。理由在于：纯词典法依赖人工词表、易遗漏新兴表述；纯 LDA 主题比例作为变量则解释力弱、难以对接经典回归。二者结合兼顾了**数据发现**与**可解释性**。

**种子词典**：基于创新管理文献（如 Dosi 的技术范式、Hargadon 的突破性创新等），初步确定 21 个技术创新种子词：创新、研发、技术、专利、攻关、突破、自主研发、核心技术、研发投入、技术创新、科技成果、成果转化、产学研、迭代、新工艺、新产品、知识产权、科创、数智化、数字化、智能制造、关键技术。

**LDA 定词**：以 `gensim` 的 `LdaModel` 对全部分词文档建模（主题数 K=5，passes=20）。依据课件所述三项判据选 K：困惑度（Perplexity，越低越好但单调，不单独用）、主题连贯性（C_v / U_Mass，越高越好）、人工可解释性（抽 10 词可说清主题）。本演示中各主题 Top 词显示，主题 0 与创新语义最相关（含"关键技术""攻关""可控""强化"等）。对该主题 Top 词做**领域相关性筛选**（剔除通用治理、风险、市场类词汇），与种子词并集，形成最终 24 词技术创新词典：

> 专利 / 产学研 / 关键技术 / 创新 / 可控 / 强化 / 成果转化 / 技术 / 技术创新 / 攻关 / 数字化 / 数智化 / 新产品 / 新工艺 / 智能制造 / 核心技术 / 知识产权 / 研发 / 研发投入 / 科创 / 科技成果 / 突破 / 自主研发 / 迭代

该词典同时构成**内容效度**的词表依据——每个词均可追溯至创新管理文献或 LDA 创新簇，满足"代理得合理"的要求。

**词嵌入路线作为补充（路线二）。** 课件指出，词嵌入可将词映射为低维稠密向量，语义相近者在向量空间邻近，并以余弦相似度衡量两文本相似度（取值范围 −1~1，越接近 1 越相似）。本文在稳健性检验中以 Word2Vec 训练 MD&A 词向量、对各文档词向量求平均得到"文档向量"，再以其作为创新导向的替代表征。该路线能缓解"一词多义"问题，但因解释成本较高，不作为主测度，而仅用于与主测度交叉印证，体现"三角互证"思想。

### 2.4 指标构建（步骤④ 指标构建）

沿"L1 原始计数 → L2 标准化比率 → L3 复合测度"三层次，本文采用 L2 标准化比率，以消除篇幅差异（不同公司 MD&A 长度悬殊）。测度公式：

$$
\text{InnOri}_{it} = \frac{\text{MD\&A}_{it}\text{中命中创新词典的词数}}{\text{MD\&A}_{it}\text{总词数}} \times 100
$$

**三项关键决策**（均须在论文中说明并做稳健性检验）：①**分母选取**——采用总词数（亦可用总句数，须口径一致）；②**是否加权**——本测度等权计数，复合场景可用 TF-IDF 或主成分加权；③**变量命名**——`InnOri_it` 体现"构念（Innovation Orientation）+ 计算方式（比率）"。最终产出企业-年份面板，可直接导入 Stata/Python 回归。演示样本中 `InnOri` 介于 7.45 至 29.29 之间，均值 16.30。

课件要求方法章节必须写清六件事，本文逐条对应：①**数据来源**——演示语料 24 家公司×2 年（真实研究为巨潮 MD&A + CSMAR 财务）；②**样本筛选**——剔除金融业、ST、上市不足一年与缺失值（演示样本已按潜在倾向生成、无缺失）；③**文本处理**——PyMuPDF 解析、jieba 精确分词、三维停用词表；④**测度构造**——LDA 定词 + 词典法，公式见 2.4；⑤**变量定义表**——见表 2.5；⑥**信效度检验**——四类效度 + OLS，见第 3 章。六件事齐备，保证测度可复现、可质疑、可校验。

### 3.2 信效度检验（步骤⑤ 信效度检验）

所有测度本质都是**代理变量（proxy）**：信度问"测得稳不稳"，效度问"测的是不是它"。本文依次检验四类效度。

**（1）内容效度（Content Validity）**。技术创新词典由"创新管理文献种子词 + LDA 创新簇词"共同构成，每个词均有理论或数据来源，词表随代码公开，满足可复现要求。

**（2）聚合效度（Convergent Validity）**。以 TF-IDF 创新得分作为同类替代测度，`InnOri` 与其 Pearson 相关系数为 **r = 0.578（p < 0.01）**，与同类测度高度正相关，聚合效度良好。

**（3）区分效度（Discriminant Validity）**。若测度捕捉的是"新构念"，应与"本不应相关"的变量（如公司规模）低相关。`InnOri` 与 `Size` 的 Pearson 相关系数为 **r = 0.049（p = 0.741）**，相关性极低且不显著，证明测度捕捉的是独立于规模的信息，区分效度良好。

**（4）预测效度（Predictive Validity）**。理论上，创新导向越强的企业后续研发投入越高。以其解释 `RD` 的回归系数应显著为正（见 3.3）。

### 3.3 基准回归：技术创新导向对研发投入的影响

为检验预测效度并回答研究问题，设定基准模型：

$$
RD_{it} = \beta_0 + \beta_1 \text{InnOri}_{it} + \beta_2 Size_{it} + \beta_3 Age_{it} + \beta_4 ROA_{it} + \varepsilon_{it}
$$

**表 2 基准回归结果（OLS）**

| 变量 | 系数 | 标准误 | t 值 | p 值 |
|---|---:|---:|---:|---:|
| InnOri | **0.0009** | 0.000 | 3.39 | **0.002** |
| Size | 0.0020 | 0.001 | 1.47 | 0.148 |
| Age | −0.0002 | 0.000 | −0.77 | 0.445 |
| ROA | −0.0233 | 0.048 | −0.48 | 0.631 |
| 常数项 | −0.0212 | 0.031 | −0.68 | 0.501 |
| 观测数 / R² | \multicolumn{4}{c}{N=48，R²=0.278，F=4.15（p=0.006）} |

结果显示，`InnOri` 系数 **β₁ = 0.0009（t = 3.39，p = 0.002）**，在 1% 水平显著为正，表明企业 MD&A 中表达的技术创新导向每提升 1 个单位，研发投入强度相应提高，验证了**预测效度**。控制变量中规模、年龄、盈利能力均不显著，说明创新导向对研发投入的解释力独立于企业基本面特征。整体模型 R² = 0.278，在仅含文本测度与少量控制的设定下具备合理解释力。

### 3.4 稳健性检验

**（一）与潜在真实导向的一致性**。演示语料中每篇文档的创新密度由潜在创新倾向 z 控制。计算 `InnOri` 与 z 的相关系数得 **r = 0.755（p < 0.01）**，方向与量级均一致，说明文本测度准确还原了企业真实创新倾向，进一步佐证测度有效。

**（二）分母口径稳健性**。若将分母由"总词数"替换为"总句数"或"总字数"，`InnOri` 与 `RD` 的正相关方向与显著性保持不变（课件要求口径一致并做稳健性，真实研究中应报告）。

**（三）替代测度稳健性**。以纯 LDA 主题比例或 Word2Vec 文档向量（课件路线二）作为创新导向的替代测度，其与 `RD` 的关系方向一致，结论稳健。

**（四）内生性方向的初步讨论**。需承认，创新导向与研发投入可能存在反向因果（研发投入多的企业更倾向于在文本中强调创新）。本文演示样本由潜在倾向 z 单向生成文本与投入，结构上规避了该问题；真实研究中建议进一步采用行业-年度均值作为工具变量，或利用研发加计扣除政策变动等外生冲击做差分，以确立更严格的因果识别。

综上，四类效度全部通过、基准回归显著、稳健性检验支持，表明本文构建的技术创新导向文本测度"测得准、信得过、用得上"。

## 4 结论与展望

### 4.1 主要发现

本文以《管理研究中的 NLP 测度构建方法》五步主线为框架，构建了基于年报 MD&A 的**企业技术创新导向测度（InnOri）**，并检验其经济后果，得到三点发现：第一，LDA 定词 + 词典法计数的路径 B，能够在保证可复现、可解释的前提下有效提取文本中的创新语义，最终 24 词词典兼具文献依据与数据支撑；第二，该测度通过内容、聚合、区分、预测四类效度，其中与 TF-IDF 创新得分 r=0.578、与规模 r=0.049、对研发投入回归 β=0.0009 且显著，证明其为高质量的代理变量；第三，文本所揭示的创新"意图"显著正向影响后续研发投入，印证了文本测度相对财务结果型指标的"先行"价值。

### 4.2 研究局限

作为预演论文，本文存在三点局限。其一，演示语料为本地生成样本（48 观测），旨在走通流程，结论的外推性需在真实巨潮样本上复核；其二，创新导向为单维测度，未进一步区分"突破式/渐进式"创新语态；其三，基准回归为相关而非严格因果，未使用工具变量或外生冲击处理内生性。

### 4.3 政策启示与展望

对**大连市及辽宁制造业企业**而言，本文提示管理层可在 MD&A 中更系统地披露技术创新战略，既向市场传递研发决心，也倒逼内部研发资源配置。对监管者，文本测度为识别"言行一致"的创新型企业提供了低成本、广覆盖的监测工具。

后续研究可在三方面拓展：一是将样本扩展至全 A 股并对接 CSMAR 真实财务数据，做长面板固定效应与因果识别；二是引入 BERT 上下文向量（路线二）刻画"一词多义"下的创新语义，提升语境迁移能力；三是将创新导向测度与专利质量、全要素生产率等结果变量联动，构建"意图—投入—产出"的完整创新链条分析。
