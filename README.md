## 一、研究简介

传统财务测度（研发投入、专利数量）只能刻画创新的**结果**，难以刻画管理层在年报"管理层讨论与分析（MD&A）"中表达出的**创新意图与战略导向**。本文遵循课件所授 **NLP 测度五步法**，系统构建一套基于 MD&A 文本的**企业技术创新导向测度（InnOri）**，并检验其经济后果。

| 步骤 | 方法 | 关键产出 |
|---|---|---|
| ① 语料获取 | 巨潮年报 MD&A（演示：本地生成 24 家×2 年） | 结构化语料库 |
| ② 文本预处理 | PyMuPDF 解析 + jieba 精确分词 + 三维停用词 | 干净分词结果 |
| ③ 特征提取 | LDA 主题模型定词 + 词典法计数（路径 B） | 24 词创新词典 |
| ④ 指标构建 | 创新词频 / 总词数 ×100（标准化比率） | 企业-年份面板 |
| ⑤ 信效度检验 | 内容 / 聚合 / 区分 / 预测四类效度 + OLS | 通过检验的变量 |

**核心结论（演示样本，N=48）**：`InnOri` 与 TF-IDF 创新得分 Pearson r=0.578（p<0.01，聚合效度）；与公司规模 r=0.049（p=0.741，区分效度）；对研发投入强度 RD 的 OLS 回归系数 β=0.0009（t=3.39，p=0.002，R²=0.278，预测效度）。文本测度"测得准、信得过、用得上"。

## 三、快速开始

```bash
# 1. 安装依赖
pip install -r code/requirements.txt

# 2. 一键运行五步流水线（生成语料→预处理→定词→构建测度→信效度检验）
python code/nlp_pipeline.py

# 3.（可选）将论文 Markdown 转为 Word
python code/md_to_docx.py
```

运行后将在 `data/` 下生成 `measure_panel.csv` 与 `results/` 结果文件，可直接导入 Stata / Python 做后续分析。

## 四、替换为真实数据

本预演使用本地生成的**演示语料**以走通完整流程并保证可复现。真实研究中只需：

1. 将 `nlp_pipeline.py` 的 `step1_corpus_acquisition()` 改为从**巨潮资讯网**下载年报 PDF；
2. 用 **PyMuPDF** 抽取每份年报的 MD&A 段落（注意去除页眉页脚、对齐到会计年度 t）；
3. 财务数据（RD、Size、Age、ROA）取自 **国泰安 CSMAR**；
4. 步骤 ②—⑤ 无需改动。

样本筛选、时间对齐、变量定义表等细节见论文第 2 章与方法章节六件事自检。

## 五、方法要点（来自课件）

- **测度即代理**：短视、创新、风险均非直接观测，论文必须解释"代理得合不合理"。
- **流程要留痕**：每步的数据来源、参数、脚本都要保存，评审第一反应是"能不能复现"。
- **效度不能省**：没有信效度检验的测度，在评审眼里等同于"自造指标"。
